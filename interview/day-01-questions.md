# Day 1 — Interview Questions

Answer each in your own words before using the hints in the lesson.

1. What is JavaScript? Where can it run?
2. What is the difference between a JavaScript engine and a runtime?
3. What are the differences between `var`, `let`, and `const`?
4. Does `const` make an object immutable?
5. List all JavaScript primitive types.
6. What does `typeof null` return? Why is it surprising?
7. What does `typeof []` return? How do you check for an array?
8. Explain dynamic typing.
9. What is the difference between type conversion and type coercion?
10. What is the output of `"5" + 2` and `"5" - 2`?
11. What is the difference between `==` and `===`?
12. What is `NaN` and how do you check for it?
13. What are template literals?
14. Is the DOM part of the JavaScript language?
15. When should you choose `let` instead of `const`?

## Output-based questions

Predict first, then execute.

```js
console.log(typeof null);
console.log(typeof []);
console.log(typeof {});
console.log("10" + 5);
console.log("10" - 5);
console.log(5 == "5");
console.log(5 === "5");
console.log(Boolean(""));
console.log(Boolean("false"));
```

3. Print a formatted employee profile using a template literal.
4. Create a small calculator using two constants.
5. Build a browser button that increments a visible counter.
