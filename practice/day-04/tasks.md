# Day 4 — Practice Tasks: Functions

Try first without copying the examples. Run in Node.js/browser console.

1. **Greeting:** Write `greet(name)` returning a greeting. Missing/undefined name should become "Guest".
2. **Calculator:** Implement add, subtract, multiply, divide. Decide and handle division by zero.
3. **Log vs return:** Write one function that logs and another that returns. Show why caller variables differ.
4. **Arrow conversion:** Convert three declarations to arrows. Explain when a regular function is preferable.
5. **Defaults:** Create `createUser(name = "Guest", role = "viewer")`; test omitted, undefined, null, and empty string.
6. **Rest:** Write `average(...numbers)`; choose a clear behavior for no arguments.
7. **Pure subtotal:** Calculate cart subtotal from `[{price, quantity}]` without mutating the input.
8. **Callback:** Write `transform(value, callback)`; call it with uppercase, number doubling, and trim callbacks.
9. **Scope quiz:** Predict which variables are accessible from nested blocks and functions; explain lexical scope.
10. **Explain aloud:** Declaration vs expression, arrow `this`, return, rest, pure function.
11. **Refactor:** Replace duplicated discount calculations with one reusable function.
12. **Edge cases:** What happens if a parameter is missing? If it is null? If a function has no return?
