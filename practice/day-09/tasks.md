# Day 9 Practice — Functions

Try without looking at the lesson first.

## Beginner
- [ ] Write add/subtract functions and return values; don't print inside.
- [ ] Convert declaration to expression and arrow.
- [ ] Test greet(name="Guest") with omitted, undefined, and null.
- [ ] Explain parameter vs argument with one example.

## Intermediate
- [ ] Implement sum(...numbers) using reduce; support zero arguments.
- [ ] Implement applyOperation(a,b,callback) with multiply/divide.
- [ ] Implement makePower(exponent) returning a power function.
- [ ] Normalize a name using a pure function.
- [ ] Factorial recursively and iteratively; compare.
- [ ] Explain why callbacks are not automatically asynchronous.

## Advanced
- [ ] Implement compose(f,g)(x) so it evaluates f(g(x)).
- [ ] Implement once(fn): execute once and cache first result.
- [ ] Implement memoize(fn) for primitive arguments; explain cache limitations.
- [ ] Implement debounce(fn, delay) and clear previous timer.
- [ ] Create a closure-based counter with increment/decrement/get.
- [ ] Explain side effects and isolate them from pure business logic.

## Interview drill
Explain callback, HOF, closure, pure function, recursion, and arrow-vs-regular function in 90 seconds.
