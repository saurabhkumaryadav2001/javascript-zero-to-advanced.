# Day 8 Practice — Arrays
Try each task before reading solutions.

## Beginner
1. Map [2,3,4,5] to squares.
2. Filter ages to values >= 18.
3. Find employee by ID; handle undefined.
4. Check any ticket is Open and every ticket has a positive ID.
5. Copy an array without its last element; don't mutate source.

## Intermediate
6. Sum prices with reduce.
7. Count word frequencies.
8. Sort salaries ascending/descending numerically.
9. Sort employee objects by age.
10. Convert {id,name} records to {value,label} options.
11. Remove duplicate primitive values using Set.
12. Flatten nested arrays two levels.

## Advanced
13. Group tickets by status into an object of arrays.
14. Pipeline: filter active → sort score → map UI model.
15. Implement pagination with slice.
16. Implement myMap with a loop/callback. Bonus: discuss sparse arrays.
17. Explain time complexity of map/filter/find/reduce and sort.
